# Ping Lab

一个仅在本机使用的静态教学页面，连接此前部署在测试网上的合约。

在项目根目录运行 `python -m http.server 8000`，然后在安装 MetaMask 的浏览器访问 `http://localhost:8000/ping-demo/`。也可以从 `ping-demo` 目录启动服务并访问根路径。

点击“连接钱包”后选择 Sepolia。发送交易需要用户在钱包中确认，消耗 Sepolia 测试币；页面不读取私钥。刷新显示回调合约的全局最新状态，只有源交易哈希与当前操作相符时才显示回调已记录。若交易被其他人的后续回调覆盖，或页面刷新后丢失当前会话，应以交易浏览器的事件记录为准。小于 100 的数字按示例配置不会请求回调；Reactive 合约处理次数用尽后也不会继续回调。

地址和验证证据见 `../notes/2026-11-13-testnet-deployments.md`。本页面依赖 MetaMask 提供的 EIP-1193 接口，并要求该钱包当前可访问 Sepolia。项目为本地实验，并未对外部署。
